# farm_pro_max

Repo này đã được reset về **model-only baseline**.

## Giữ lại

- Model/scene **Giảng đường 4 UET** hiện tại.
- Bộ asset GLB của phòng học mà GD4 đang dùng.
- Một viewer Babylon.js tối thiểu để mở và kiểm tra model.

## Đã loại khỏi baseline

Chapter 0/1 cũ, map cũ, thoại, narrative, audio, gameplay, interaction, test, playtest, tài liệu sản xuất và các file điều phối cũ không còn nằm trong `main`.

## Chạy preview

```bash
npm install
npm run dev
```

Baseline này chỉ dùng để giữ GD4 làm mốc hình học. Các phần còn lại có thể dựng lại bằng Babylon.js Editor.
