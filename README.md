# Người Thứ Chín — working title

Browser-first 3D first-person psychological investigation game.

## Status
**Phase 0 — Pre-production / foundation**

This repository is the source of truth for:
- game vision
- story bible
- technical architecture
- interaction design
- art/audio direction
- project decisions
- progress and resume state

## Core promise
- True 3D first-person exploration.
- Smooth movement and camera.
- Tactile object interactions.
- Investigation-focused gameplay.
- "Knowledge Changes Reality": discoveries can change the world.
- Familiar Vietnamese spaces that slowly become unreliable.
- Desktop web first.
