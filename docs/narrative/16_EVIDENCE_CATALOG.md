## E18 — Rental-room recorder
Pre-recorded transcript:
“Khang: Nếu mày nghe được cái này thì đừng cố gọi tao bằng tên.”
The recording ends.

After playback, An says “Khang?” live in the room and receives no immediate answer. The causal response — “Đấy. Mày lại làm nó ổn định hơn.” — occurs only later through the KCR-D live signal, not inside this recording.

Function: warns that naming can stabilize the witness-state without allowing a pre-recorded file to answer a future live line.

## Evidence writing rule
No document exists only to explain lore. Each evidence item either changes a hypothesis, proves a timeline point, or alters a game-state condition.
