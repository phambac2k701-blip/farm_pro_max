# 13. Continuity rules

Narrative workers must check:
- would this protagonist actually say this?
- would they notice this?
- would they ask for help here?
- would they make this mistake?
- would they react this strongly?
- is this option available because of player agency, or does it contradict established character?
- has familiarity changed since an earlier scene?

If a scene requires the protagonist to behave out of character to work, revise the scene before revising the character.
