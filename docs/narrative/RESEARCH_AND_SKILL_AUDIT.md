# RESEARCH AND SKILL AUDIT

## Environment
Available Agent Skills were inspected. The environment exposed plugin-management as the relevant installed skill; it did not expose a native story architect or game narrative skill.

## Public candidates assessed
1. `narrastory/story-architect-skill` — MIT. Useful for project state, canon, decisions, timeline, knowledge-state and linting concepts. Repository is public and active but small (3 stars, 0 forks, 0 open issues at audit time; created 2026-07-31). Adopt methodology only.
2. `Stanestane/narrative-design-skills` — very new public repo (created 2026-09-01; 0 stars at audit). Quest design skill has strong player-verb/state-change emphasis. Adopt concepts only.
3. `fcsouza/agent-skills` — GPL-3.0, 20 stars at audit. Narrative coherence material useful, but license makes blind copying inappropriate. Use as conceptual reference only.
4. `myshenoy/skills-open-source` — MIT, 0 stars at audit. Contains a game-narrative skill oriented toward deduction, player imagination, and NPC agency. Adopt relevant conceptual checks only.
5. `sb-dev/narrative-production-skills` — MIT, 1 star at audit, updated 2026-09-28. Strong selection/approval, continuity and targeted-revision methodology. Adopt concepts only.

## Adopted principles
- explicit state and source-of-truth ownership;
- planned != canonical;
- selection != approval;
- player verbs and agency;
- deduction fairness;
- NPC agency;
- clue setup/payoff;
- upstream-cause revision;
- continuity audits.

## Explicitly excluded
- novel-first scaffolding;
- screenplay-specific assumptions;
- mandatory Hero's Journey / Three-Act / Save the Cat;
- combat quest economies;
- generic reward systems;
- automatic rewriting without approval;
- any external story canon.

## Skill test
Three synthetic directions were fed through the project-local skill:
A. erased person;
B. institutional role;
C. reality-writing archive.

Expected distinctions were causal mechanism, theme, gameplay and KCR. The critique pass was required to find cliché, coincidence, clue-fairness, and gameplay weaknesses. The skill passed because it attacked different failure modes per candidate rather than returning the same generic critique.
