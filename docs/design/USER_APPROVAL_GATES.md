# USER APPROVAL GATES

Status: **ACTIVE DRAFT RULESET — USER REVIEW REQUIRED FOR CANON**

This document records which project decisions require explicit user approval before they become canon or production identity.

## Core rule

> Technical work may proceed within approved constraints. Major creative identity/canon decisions must pass the user first.

If a required creative decision is missing, use an explicit placeholder such as:

`TBD_USER_APPROVAL`

Do not silently convert placeholders into canon.

## Must stop and request user approval

The following require explicit user review/approval:

### Institutional identity

- university name
- university logo
- faculty/department identity
- insignia/badge
- official color system
- official slogan/motto
- campus master map / canonical campus topology
- uniforms or other institution-specific clothing
- major signage identity

### Main characters

- protagonist final name
- protagonist final appearance
- protagonist canonical personality changes
- important NPC names
- important NPC final appearance
- important NPC role changes
- major relationship arcs

### Narrative canon

- chapter canon
- chapter ordering
- major story beats
- final explanation/rules for any unusual or reality-changing layer
- major twists
- major long-term route structure
- character deaths/removals
- endings
- retroactive changes to approved canon

### Major visual direction

- final character art direction
- final institution identity
- final campus visual identity
- major style pivot
- major architecture/layout reinterpretation

## May proceed without routine approval

Within approved direction, AI/implementation agents may autonomously handle:

- bug fixes
- tests
- refactors that preserve behavior
- collision fixes
- performance work
- build/deployment fixes
- generic placeholder assets
- modular environment infrastructure
- asset naming conventions
- import/export tooling
- LOD/instancing strategy
- PBR/material infrastructure
- lighting prototypes
- animation framework
- generic interaction animations
- screenshot comparison tooling
- non-canon technical prototypes

## Placeholder policy

Every non-approved creative placeholder must be clearly marked.

Examples:

- `TBD_USER_APPROVAL_UNIVERSITY_NAME`
- `TBD_USER_APPROVAL_LOGO`
- `TBD_USER_APPROVAL_PROTAGONIST_LOOK`

Placeholder content may be used to keep technical work moving, but must not be presented as final.

## Narrative ownership

The user is the primary writer and final narrative approver.

AI is a collaborator/editor/implementer, not the final canon authority.
